## Cómo reportar cambios

Si encontraste un cambio que no está documentado aquí:
1. Abre un Issue en GitHub
2. Describe el cambio
3. Incluye pasos para reproducir si es un bug

## Convenciones de versioning

Usamos [Semantic Versioning](https://semver.org/lang/es/):
- **MAJOR** - Cambios incompatibles
- **MINOR** - Nuevas características compatibles
- **PATCH** - Correcciones de bugs

Formato: `MAJOR.MINOR.PATCH`
