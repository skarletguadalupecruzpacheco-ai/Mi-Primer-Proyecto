# 🤝 Cómo contribuir

¡Gracias por querer mejorar este proyecto! Aquí está cómo hacerlo.

## 🎯 Antes de empezar

- Lee el archivo `README.md` para entender el proyecto
- Consulta `FAQ.md` para ver si tu idea ya fue sugerida
- Revisa los issues existentes para evitar duplicados

## 🚀 Proceso de contribución

### Paso 1: Fork el proyecto
1. Ve a https://github.com/skarletguadalupecruzpacheco-ai/Mi-Primer-Proyecto
2. Haz clic en **"Fork"** (arriba a la derecha)
3. Clona tu fork: `git clone https://github.com/TU-USUARIO/Mi-Primer-Proyecto.git`

### Paso 2: Crea una rama
```bash
git checkout -b feature/mi-mejora
# o
git checkout -b fix/corregir-algo
```

### Paso 3: Haz tus cambios
- Modifica los archivos que necesites
- Sigue las prácticas recomendadas
- Prueba que funcione

### Paso 4: Commit y push
```bash
git add .
git commit -m "Descripción clara de cambios"
git push origin feature/mi-mejora
```

### Paso 5: Pull Request
1. Ve a tu fork en GitHub
2. Haz clic en **"Compare & pull request"**
3. Llena la descripción
4. Envía el PR

## 📋 Tipos de contribuciones aceptadas

### 🐛 Bugs
- Reporta errores que encuentres
- Incluye pasos para reproducir
- Especifica tu navegador y SO

### ✨ Mejoras
- Nuevas lecciones de Python
- Mejor documentación
- Mejoras de UX/UI
- Optimizaciones de performance

### 🔄 Traducciones
- Traducir a otros idiomas
- Adaptar contenido regional

### 📚 Documentación
- Corregir errores de tipeo
- Aclarar instrucciones
- Agregar ejemplos

## 📝 Guía de estilo

### Código HTML/CSS/JS
- Indentación: 2 espacios
- Comillas simples para JS
- Nombres descriptivos
- Comentarios claros

### Documentación
- Markdown limpio
- Emojis para facilidad visual
- Enlaces funcionales
- Ejemplos prácticos

### Commits
```
Bueno:     "Agregar lección sobre diccionarios"
Malo:      "cambios"

Bueno:     "Corregir error en tema oscuro"
Malo:      "fix bug"
```

## ✅ Checklist antes de enviar PR

- [ ] Probé que funcione en Chrome y Firefox
- [ ] El código sigue el estilo del proyecto
- [ ] Agregué comentarios si es necesario
- [ ] Actualicé la documentación
- [ ] No hay cambios no relacionados
- [ ] Descriptión clara del PR

## 🎓 Ideas para contribuir
