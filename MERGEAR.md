## 🎯 Cómo Mergear (3 opciones)

### OPCIÓN 1: Desde GitHub Web (Más fácil) ⭐ RECOMENDADO

**Paso 1: Ir a Pull Requests**
1. Ve a: https://github.com/skarletguadalupecruzpacheco-ai/Mi-Primer-Proyecto
2. Haz clic en **"Pull requests"**
3. Haz clic en **"New pull request"**

**Paso 2: Seleccionar ramas**
1. Base: **main** (rama destino)
2. Compare: **mejoras** (rama con cambios)
3. Haz clic en **"Create pull request"**

**Paso 3: Rellenar información**
- Título: `Agregar documentación profesional y configuración v1.1`
- Descripción: Copia el texto de abajo ⬇️
- Haz clic en **"Create pull request"**

**Paso 4: Mergear**
1. Baja en la página PR
2. Haz clic en **"Merge pull request"**
3. Confirma haciendo clic en **"Confirm merge"**

**¡LISTO! ✅ Tus cambios están en main**

---

### OPCIÓN 2: Desde Terminal (Para expertos)

```bash
# Ir a tu proyecto local
cd Mi-Primer-Proyecto

# Actualizar repositorio local
git fetch origin

# Cambiar a main
git checkout main

# Mergear mejoras a main
git merge origin/mejoras

# Hacer push
git push origin main

# ¡Listo!
echo "✅ Merge completado"
```

---

### OPCIÓN 3: GitHub CLI (Si tienes gh)

```bash
# Crear PR automáticamente
gh pr create --base main --head mejoras \
  --title "Agregar documentación profesional v1.1" \
  --body "Se agrega documentación completa, configuración profesional y plantillas de GitHub"

# Mergear automáticamente
gh pr merge <PR_NUMBER> --merge

# ¡Listo!
```

## 🆘 Si hay conflictos

Si GitHub dice que hay conflictos:

```bash
# Desde terminal
git checkout main
git pull origin main
git merge origin/mejoras

# Resuelve conflictos en tu editor
# Luego:
git add .
git commit -m "Resolver conflictos"
git push origin main
```

Si prefieres por GitHub:
1. Abre el PR en GitHub
2. Haz clic en "Resolve conflicts"
3. Resuelve visualmente
4. Confirma cambios
5. Mergea
