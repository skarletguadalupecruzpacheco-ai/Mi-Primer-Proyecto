# 📦 Guía de Instalación - Python Interactivo

Aquí aprenderás cómo descargar y usar este proyecto en tu PC.

## ⭐ Opción 1: Lo más rápido (Recomendado)

### Paso 1: Descargar el archivo
1. Ve a https://github.com/skarletguadalupecruzpacheco-ai/Mi-Primer-Proyecto
2. Haz clic en el botón verde **"Code"**
3. Selecciona **"Download ZIP"**
4. Espera a que se descargue

### Paso 2: Descomprimir
1. Abre tu carpeta de Descargas
2. Haz clic derecho en `Mi-Primer-Proyecto-main.zip`
3. Selecciona **"Extraer aquí"** o **"Descomprimir"**

### Paso 3: Abrir el archivo
1. Abre la carpeta descomprimida
2. Busca el archivo `Python Interactivo.html`
3. **¡Haz doble clic!** Se abrirá en tu navegador

✅ **¡Listo!** Ya puedes empezar a aprender.

## 💻 Opción 2: Usando Visual Studio Code (Para programadores)

### Requisitos
- Descargar [Visual Studio Code](https://code.visualstudio.com)
- Extensión "Live Server" (gratuita)

### Instalación

**Paso 1: Instalar Live Server**
1. Abre Visual Studio Code
2. Ve a **Extensions** (ícono de cuadraditos a la izquierda)
3. Busca **"Live Server"** (por Ritwick Dey)
4. Haz clic en **"Install"**

**Paso 2: Descargar el proyecto**
1. Abre una terminal en VS Code (Ctrl + `)
2. Escribe:
```bash
git clone https://github.com/skarletguadalupecruzpacheco-ai/Mi-Primer-Proyecto.git
cd Mi-Primer-Proyecto
```

**Paso 3: Abrir en navegador**
1. Haz clic derecho en `Python Interactivo.html`
2. Selecciona **"Open with Live Server"**
3. ¡Se abrirá automáticamente en tu navegador!

✅ **¡Listo!** Ahora puedes editar y ver cambios en tiempo real.

## ❓ Soluciones a problemas comunes

### "No se abre el archivo"
- Intenta abrirlo con otro navegador (Chrome, Firefox, Edge)
- Asegúrate de que es un archivo `.html` (no `.txt`)

### "El confeti no funciona"
- Algunos navegadores necesitan conexión a internet para el efecto confeti
- Verifica tu conexión
- O usa Chrome/Firefox (mejor compatibilidad)

### "¿Dónde está mi progreso?"
- El progreso se guarda mientras estés en la página
- Si cierras y reabres, se reinicia (esto es normal en HTML puro)
- Si quieres persistencia, necesitarías agregar localStorage (más avanzado)

### "No puedo copiar el código"
- Algunos navegadores pueden bloquear esto
- Intenta con Chrome o Firefox
- O cópialo manualmente seleccionando el texto
