# 🐍 Python Interactivo — Cuaderno de Código

¡Bienvenida a tu primer proyecto! Este es un **cuaderno interactivo para aprender Python** de forma divertida y gamificada.

## ✨ Características

✅ **8 lecciones completas** sobre Python básico  
✅ **Modo oscuro/claro** para comodidad visual  
✅ **Efecto confeti** cuando respondes correctamente  
✅ **Botón copiar código** para practicar en Replit o VS Code  
✅ **Sistema de puntos** para motivarte  
✅ **Diseño responsivo** (funciona en PC, tablet y móvil)  
✅ **Pistas interactivas** para cada ejercicio  

## 🚀 Cómo usar

### Opción 1: Abrir en el navegador (Lo más fácil)
1. Descarga el archivo `Python Interactivo.html`
2. Haz doble clic en él (se abrirá en tu navegador por defecto)
3. ¡Comienza a aprender!

### Opción 2: Desde Visual Studio Code
1. Abre VS Code
2. Crea una carpeta llamada `Mi-Primer-Proyecto`
3. Copia el archivo `Python Interactivo.html` en esa carpeta
4. Haz clic derecho en el archivo → **Open with Live Server**
5. ¡Listo! Se abrirá en tu navegador

### Opción 3: Desde cualquier editor de texto
1. Abre el archivo `.html` con Notepad, VS Code, Sublime Text, etc.
2. Abre el archivo en tu navegador arrastrándolo a la ventana del navegador

## 📚 Lecciones incluidas

1. **¡Bienvenida a Python!** - Aprende qué es Python y por qué es genial
2. **Variables** - Guarda datos en "cajitas" etiquetadas
3. **Tipos de datos** - int, float, str, bool
4. **Condicionales** - if / elif / else
5. **Bucles** - Repite código con for y while
6. **Listas** - Guarda varios datos en orden
7. **Funciones** - Crea bloques reutilizables
8. **Reto final** - Combina todo lo aprendido

## 💡 Cómo practicar

Cada lección tiene:
- 📖 **Explicación** clara con ejemplos
- 💻 **Bloque de código** (puedes copiar con un clic)
- ✏️ **Ejercicio** con preguntas de opción múltiple
- 💡 **Pista** (si necesitas ayuda)

## 🎯 Próximos pasos después del curso

Una vez que termines este cuaderno:

1. **Crea tu primer programa en Python:**
   - Usa [Replit](https://replit.com) (no necesita instalación)
   - O descarga [Visual Studio Code](https://code.visualstudio.com) + Python

2. **Practica escribiendo código:**
   - Crea un juego simple (piedra, papel, tijeras)
   - Un calculador
   - Un programa que cuente historias

3. **Aprende más:**
   - [Python.org](https://python.org) - Documentación oficial
   - [Real Python](https://realpython.com) - Tutoriales en profundidad
   - YouTube - Busca "Python para principiantes"
