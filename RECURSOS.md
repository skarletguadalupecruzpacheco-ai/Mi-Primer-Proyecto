## 🏗️ Proyectos para practicar

Después de aprender lo básico, crea estos proyectos:

### Nivel 1: Muy fácil ⭐
- [ ] Programa que pida tu edad y te diga en qué año naciste
- [ ] Calculadora simple (suma, resta, multiplicación)
- [ ] Juego de piedra, papel, tijeras
- [ ] Adivinador de números

### Nivel 2: Fácil ⭐⭐
- [ ] Lista de tareas (to-do list)
- [ ] Trivia/Quiz sobre un tema
- [ ] Sistema de notas (guardar y leer notas)
- [ ] Conversor de temperaturas

### Nivel 3: Intermedio ⭐⭐⭐
- [ ] Juego de ahorcado
- [ ] Chat bot simple
- [ ] Analizador de textos (contar palabras, letras, etc.)
- [ ] Descargador de imágenes de internet

### Nivel 4: Avanzado ⭐⭐⭐⭐
- [ ] Web scraper (extraer datos de websites)
- [ ] Bot de Discord o Telegram
- [ ] Dashboard con gráficos
- [ ] API REST simple

- **NumPy** - Cálculos numéricos rápidos

- **Requests** - Descargar datos de internet

- **Pygame** - Crear videojuegos 2D
- **Panda3D** - Juegos 3D

- **Discord.py** - Crear bots para Discord
- **Tweepy** - Automatizar Twitter
- **TensorFlow** - Machine Learning

## 🎯 Ruta de aprendizaje sugerida

```
Semana 1-2: Fundamentos
├── Variables, tipos, operadores
├── Condicionales (if/else)
└── Bucles (for/while)

Semana 3-4: Estructuras
├── Listas y tuplas
├── Diccionarios
└── Funciones

Semana 5-6: Aplicaciones
├── Manejo de archivos
├── Módulos y librerías
└── Errores (try/except)

Semana 7+: Proyectos reales
├── Elige un proyecto del nivel 2-3
├── Usa Google y Stack Overflow
└── ¡Celebra tu avance!
```

## 🐛 Cómo resolver errores

Cuando te atorques:

1. **Lee el mensaje de error** - Dice exactamente cuál es el problema
2. **Googlea el error** - Alguien ya lo resolvió
3. **Usa Stack Overflow** - Busca o haz una pregunta
4. **ChatGPT o Copilot** - Pregunta al AI (pero entiende la respuesta)
5. **Pide ayuda en comunidades** - Los programadores son generosos

**Consejo:** Los mejores programadores NO memorizan todo. **Buscan, preguntan y copian código**. Eso es profesionalismo.
